# Decisions

A log of technical decisions, one line each with the reason. Newest at the bottom.

| # | Date | Phase | Decision | Reason |
|---|------|-------|----------|--------|
| 1 | 2026-11-19 | Plan | Next.js app lives at the repo root (no `src/`), docs stay in `docs/`. | Matches the folder structure in SPEC.md (`app/`, `components/`, `lib/`, `content/`). |
| 2 | 2026-11-19 | Plan | Curriculum read from `docs/Programming Learning Journey - Learning Plan.pdf`. | `docs/curriculum.pdf` does not exist; this is the only curriculum file. |
| 3 | 2026-11-19 | Plan | All derive functions take `today` as an argument. | Keeps them pure and testable; the client passes the real date for "next session". |
| 4 | 2026-11-19 | Plan | Road map, points chart and badge medallions are hand-built SVG. | Spec asks for code-drawn visuals; avoids extra dependencies. |
| 5 | 2026-11-19 | 0 | Next.js 16.4.6, React 19.3, Tailwind 4.3, Vitest 5, ESLint 9.39. | Latest stable; Keystatic peers accept React 19 / Next ≥14; ESLint 9 for plugin compatibility. |
| 6 | 2026-11-19 | 0 | TypeScript 6.0.3 instead of 7.x. | typescript-eslint (via eslint-config-next) requires TS < 6.1. |
| 7 | 2026-11-19 | 0 | Basic Auth lives in `proxy.ts`, not `middleware.ts`. | Next 16 renamed Middleware to Proxy; same behaviour. |
| 8 | 2026-11-19 | 0 | `next-themes` with `defaultTheme="system"`. | Light for anyone without a dark system setting (spec "light by default"), but respects a dark system preference and remembers a manual choice. |
| 9 | 2026-11-19 | 0 | noindex via metadata `robots` **and** an `X-Robots-Tag` header; `robots.txt` disallows `/`. | Covers HTML pages and non-HTML files (PDFs) alike. |
| 10 | 2026-11-19 | 0 | Playwright installed in Phase 0; QA scripts live in `scripts/qa/`. | Needed to check theme/no-flash for the Phase 0 gate; reused for screenshots. |
| 11 | 2026-11-19 | 1 | One root layout (`app/layout.tsx`: html, fonts, theme); site chrome goes in `app/(site)/layout.tsx`; Keystatic at `app/keystatic` without chrome. | Avoids multiple root layouts, which would need the experimental `global-not-found`. |
| 12 | 2026-11-19 | 1 | Storage switch via `NEXT_PUBLIC_KEYSTATIC_STORAGE=github` + `NEXT_PUBLIC_KEYSTATIC_GITHUB_REPO=owner/repo`. | The admin UI runs in the browser, so the switch must be a public env var. |
| 13 | 2026-11-19 | 1 | Session entry slug = session number (text field, digits only) → `content/sessions/12.mdoc`, URL `/sessions/12`. | Keystatic slugs must be text; this makes number, filename and URL one thing. |
| 14 | 2026-11-19 | 1 | Monthly note slug = month `YYYY-MM` (validated pattern). | Same reason; one note per month guaranteed by the filename. |
| 15 | 2026-11-19 | 1 | Points entry slug auto-generated as `<today>-<title>`. | Repeated titles like "Exercise completed" would otherwise collide; sorts by date on disk. |
| 16 | 2026-11-19 | 1 | Points `activity` is a Keystatic conditional: choosing a rule shows a Points field prefilled with that rule's value. Rules list lives in `lib/model/points-rules.ts`; validator fails if settings drift. | Keystatic can't read one entry to prefill another (Question 7). |
| 17 | 2026-11-19 | 1 | Added optional `order` to badges and fields, and `howToEarn` to manual badges. | Needed to control badge-wall/field-card order and to show how to unlock a manual badge (spec: locked badges show how to unlock). |
| 18 | 2026-11-19 | 1 | Added optional `completedOn` (sprint), `doneOn` (ready check), `finishedOn` (project). | Question 5 — needed for badge dates and monthly report stats. |
| 19 | 2026-11-19 | 1 | Validator lives in `lib/content/validate.ts`; CLI `scripts/validate-content.ts` (run with tsx); also a Vitest test. | Keeps all content access inside lib/content as the spec requires. |
| 20 | 2026-11-19 | 1 | Example session PDF generated by `scripts/make-sample-pdf.mjs` (no dependency). | Spec asks for a sample PDF; avoids adding a PDF library. |
| 21 | 2026-11-19 | 1 | Sprint topics kept in the PDF's reading order (left column, then right column). | The PDF lays topics out in two columns; this is the most faithful order. |
| 22 | 2026-11-19 | 2 | Overall progress = (done sprints + ticked-check share of in-progress sprints) / all sprints; an in-progress sprint caps at 95%, overall at 99% until all are done. | Mastery decides: ticking every check isn't "done" until you mark the sprint Done. |
| 23 | 2026-11-19 | 2 | "Sessions planned" in a report = every session dated that month (held + planned + cancelled). | Reads naturally as "4 of 5 planned sessions held". |
| 24 | 2026-11-19 | 2 | Badge unlock date = date the threshold was first crossed; unknown (null) when a needed date is missing; points badges re-lock if a correction drops the total below N. | Derived purely from content, as the spec asks. |
| 25 | 2026-11-19 | 2 | Test fixtures live in `tests/fixtures.ts`. | Keeps lib/derive free of test-only code. |
| 26 | 2026-11-19 | 3 | Mobile nav is a native `<dialog>` bottom sheet. | Focus trap, Esc, inert background and return focus come built in — fewer bugs than a hand-rolled drawer. |
| 27 | 2026-11-19 | 3 | "Today" on the client comes from `useSyncExternalStore` (null on the server). | No hydration mismatch and no setState-in-effect; next session is computed in the browser as the spec asks. |
| 28 | 2026-11-19 | 3 | Shiki with the JavaScript regex engine, only Python + C grammars, and two custom themes built from the palette. | Small, build-time only, no WASM; colours match the site in both themes. |
| 29 | 2026-11-19 | 3 | Sprint page: on phones the checklist + files column comes first; on desktop it's a sticky side column. | The ready checks are the most important thing on a sprint page. |
| 30 | 2026-11-19 | 3 | `lib/labels.ts` for display helpers (sprint label, phase label, plural). | Formatting only; keeps lib/derive unchanged (no mid-course changes). |
| 31 | 2026-11-19 | 3 | Screenshots wait for `load` + 400 ms rather than `networkidle`. | Next's link prefetching keeps the network busy; networkidle timed out. |
| 32 | 2026-11-19 | 4 | Pinned `@markdoc/markdoc` to 0.4.0. | Keystatic 0.6.10 bundles 0.4.0; one copy means its nodes render with the same library version. |

| 35 | 2026-11-19 | 4 | List filters (sessions, resources) live in the URL query; a Suspense fallback shows the full list in the static HTML. | Shareable, reload-safe, and works before JavaScript loads. |
| 36 | 2026-11-19 | 4 | PDF preview is an `<iframe>` created only when "Preview here" is pressed. | Large PDFs aren't downloaded until someone asks to see them. |
| 37 | 2026-11-19 | 4 | `/plan` text is written into the page from the curriculum PDF (sections 01–06), using the first name from settings. | The plan is fixed curriculum text, not content edited week to week. |
| 38 | 2026-11-19 | 4 | Road map: one SVG segment per row, stretched to the row height, with seeded wobble; phase headings are rows of the same list. | The path always connects whatever the card heights, and looks drawn rather than generated. |
